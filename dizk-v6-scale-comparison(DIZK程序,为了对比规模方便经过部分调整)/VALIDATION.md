本次检验是 Windows 上的功能检验，目标运行环境仍为用户的 Ubuntu 18.04 虚拟机。功能检验数据不作为论文性能数据。

## 本次已实际完成

- 固定作者提交的 186 个构建文件按 SHA-256 核对；作者源码保持原字节。
- 新适配器与作者源码使用 Amazon Corretto JDK 8 `1.8.0_504`、Maven 3.9.9 重新编译成功；Spark 2.2.2/Scala 2.10，144 个运行依赖。
- 新规模电路 1,024 条约束（341 乘法、683 线性）执行真实 Serial Setup/Prove/Verify 和 Spark local[16] Setup/Prove/Verify 各一次；两次均 verified=true、退出码0，正式输入和 CSV 校验通过。它们是功能 fixture，不是 MC=1 的 295,668 条正式实验。
- 生成器、输入/结果守卫测试覆盖真实数学满足性、全部变量参与、实际 N/Q 比例、公开输出失配、文件篡改、scope 互斥、输入运行后改变与拒绝覆盖已有结果。
- Java 导入负面测试覆盖严格模式/自测模式拒绝规模输入、实际分类计数不符、same_statement 标错和错误素域；不依赖只有 Python 守卫才安全。
